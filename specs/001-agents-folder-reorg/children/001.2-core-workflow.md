# Goal

Move the six core files into `agents/core/` and the three workflow files into `agents/workflow/`, updating every importer (internal and external). These two groups move together because they are mutually dependent (see `../design.md` §3).

# Work

1. Create `agents/core/` and `agents/workflow/`; move the nine files.
2. Rewrite internal cross-imports among the moved files (preserve each file's extension convention):
   - core→core and workflow→workflow stay `./<name>`.
   - core→workflow: `pi-agent.ts` and `pi-agent-configs.ts` import `AgentInterface` from `workflow-interface` → `../workflow/workflow-interface`.
   - workflow→core: `workflow.ts`, `workflow-interface.ts`, `workflow-types.ts` imports of `raw-pi-agent`/`pi-agent-configs`/`pi-agent-types`/`pi-agent-utils` → `../core/<name>`.
   - core→integrations: `pi-agent.ts` import of `mcp-bridge` (currently `./integrations/mcp-bridge.js` after `001.1`) → `../integrations/mcp-bridge.js`.
3. Re-point importers still at `agents/` root (`meeting.ts`, `swarm.ts`) to `./core/<name>` for `raw-pi-agent`/`pi-agent-configs`/`pi-agent-types`.
4. Update every external importer (full list in `../design.md` §4): `tests/` (8 files), `examples/` (~19 files incl. `coding_team/`), `memory/extractor_agent.ts`, `quick-start.ts`, and `web_app/backend/src/` (5 files: `routes/agents.ts`, `routes/workflows.ts`, `services/agent-manager.ts`, `services/workflow-manager.ts`). `core` files → `<agents>/core/<name>`; `workflow` files → `<agents>/workflow/<name>` (adjust the relative prefix per file).
5. Remove the dead `@agents/*` alias from `web_app/backend/tsconfig.json` (the `paths` block). Leave `include` as-is (`**` already matches subfolders).
